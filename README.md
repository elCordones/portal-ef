# 🏅 Portal d'Educació Física — SdA Hub (LOMLOE · Decret 175/2022)

🌐 **Portal Web en Viu (GitHub Pages):** **[https://elcordones.github.io/portal-ef/](https://elcordones.github.io/portal-ef/)**

Portal docent centralitzat de **Situacions d'Aprenentatge (SdA)** d'Educació Física per a Cicle Superior d'Educació Primària (5è i 6è), dissenyat amb arquitectura *Mobile-First* (VitePress) per ser consultat a peu de pista des de l'iPhone/tauleta i amb aplicacions web interactives per a Chromebooks.

---
